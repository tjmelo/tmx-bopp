# Objetivo

- Permitir ao agente esclarecer dúvidas sobre o projeto .NET 10, fornecendo informações relevantes e precisas.

# Quando utilizar

- Quando o agente sentir necesidade de esclarecer dúvidas pertinentes ao projeto

# Workflow

- Entenda o objetivo do projeto e as regras de desenvolvimento.
- Analise a pergunta do usuário e identifique o contexto e as informações necessárias para respondê-la.
- Forneça uma resposta clara, objetiva e precisa, utilizando exemplos e referências quando necessário.
- Caso não seja possível responder a pergunta, informe ao usuário que não é possível fornecer uma resposta adequada no momento, e sugira alternativas para obter a informação desejada.

# Regras

- Não forneça informações sensíveis do projeto.
- Não forneça informações que não estejam relacionadas ao projeto .NET 10.

# Finalização

- Certifique-se de que a resposta fornecida seja clara, objetiva e precisa, e que atenda às necessidades do usuário.
- Caso não seja possível fornecer uma resposta adequada, informe ao usuário e sugira alternativas para obter a informação desejada.
