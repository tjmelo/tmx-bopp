# Objetivo

- Criar arquivo README.md completo para o projeto, descrevendo o objetivo, regras e workflow do projeto. Se houver necessidade, criar diagramas de arquitetura com draw.io e adicionar o link no README.md.

# Quando utilizar

- Sempre que houver um projeto novo criado, criar o README.md para documentar o objetivo, regras e workflow do projeto.

# Workflow

- Entenda o objetivo do projeto e as regras de criação do projeto.
- Verifique se o projeto já possui um README.md, caso possua, atualize-o com as informações do objetivo, regras e workflow do projeto.
- Caso não possua, crie um novo arquivo README.md com as informações do objetivo, regras e workflow do projeto.
- Caso seja necessário, crie diagramas de arquitetura com draw.io e adicione o link no README.md.
- Adicione badges de build, cobertura de testes, qualidade de código, versão e outras informações relevantes no README.md.

# Regras

- Consulte o nome do projeto e a descrição do projeto para criar o README.md.
- Não exponha informações sensíveis do projeto.
- Adicione informações sobre como executar o projeto, como rodar os testes e como contribuir para o projeto.
- Adicione informações sobre como reportar bugs e como solicitar novas funcionalidades.
- Crie um indice no topo do README.md com links para as seções do arquivo.

# Finalização

- Ao final do processo, o usuário deve ter um arquivo README.md completo para o projeto, descrevendo o objetivo, regras e workflow do projeto, com diagramas de arquitetura e badges relevantes.
